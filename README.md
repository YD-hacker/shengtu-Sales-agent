# 盛途 SalesAgent — IT人才服务AI智能销售助手

> 基于大语言模型的智能销售对话系统。面向IT人才猎聘/岗前实训场景，通过企业微信与潜在学员对话，自动完成从破冰到报备的全流程销售转化。

> 系统采用「关键节点模板直出 + 非关键节点LLM自主决策」分层架构，兼顾合规红线与对话自然度。

---

## 项目简介

盛途SalesAgent 是一个 **AI智能销售Agent**，核心任务是替代传统「HR电销 + 面试官说服」的双人接力模式，由单一Agent完成：

1. **HR角色**：初步筛选（学历/年龄/城市/方向）、邀约面试
2. **面试官角色**：深度说服（行业前景/案例举证/异议化解/费用说明/协议解读/逼单收尾）

Agent 通过企业微信文字聊天完成全流程，遵循七步邀约SOP，支持零基础小白和有经验求职者两条差异化路径。

## 核心特性

### 销售流程
- **双路径状态机**：小白路径（7步SOP）+ 求职者路径（岗前考核快速通道），共10个状态节点
- **22种意图识别**：双层识别（正则 + LLM），含辱骂检测、竞品对比、差评质疑等
- **信任门禁**：信任分（0-100）控制推进节奏，日衰减+防刷机制+hysteresis防抖
- **线索分层**：S/A/B/C四级，差异化异议策略、唤醒间隔、车费报销

### 异议处理
- **9类异议覆盖**：犹豫/学不会/没时间/太远/不信任/价格 + 差评/骗局质疑/竞品对比
- **5步法 + 3策略模式**：共情→探因→举证→重构→行动，支持标准/备选/直接三种模式
- **面试官级话术**：融合电销实战话术，含行业数据举证、ROI计算、案例引用

### 合规与安全
- **三层防护**：全局违禁词 + 阶段敏感词 + 动态红线
- **费用白名单**：show_fee/invite/reject_qualify 阶段合规豁免
- **辱骂检测**：识别脏话/辱骂，2次触发人工转接
- **模糊确认降级**：短消息（≤3字）在关键阶段不直接推进状态
- **LLM熔断**：连续失败3次自动切换模板模式

### 智能增强
- **对话人性化**：可变延迟(0.5-3s) + 逐字打字节奏 + 长回复智能分段 + 结尾钩子反问 — 消除机器人感
- **向量记忆**：语义检索历史对话，用户隔离，原子持久化
- **深度画像**：决策风格/经济压力/沟通风格/情绪状态/转化概率
- **FAQ知识库**：28条标准化FAQ，覆盖8大分类，支持语义检索
- **A/B实验**：话术变体自动生成+合规检查，数据驱动优化
- **工具调用**：LLM可查询用户信息、检查资格、匹配校区、获取案例

### Skill插件系统
- **14个注册Skill**：统一执行容器（参数校验/超时/异常捕获）
- **4个新增Skill**：合规自检/异议处理/对话挽回/FAQ问答

## 状态机架构

```
【小白路径（零基础转行）】
icebreak → qualify → match_campus → show_fee → invite → report_info → completed
                        ↑              ↓ (价格异议回退)
                        └──────────────┘

【求职者路径（有经验内推）】
icebreak → pre_assessment ──(通过)→ invite → report_info → completed
                            └──(未通过)→ pre_training → qualify → ...（标准路径）

【非保障班路径】
icebreak → qualify → reject_qualify → show_fee(non-guarantee) → invite
```

### 信任门禁

| 信任值 | 可到达状态 |
|--------|-----------|
| ≥30 | icebreak / qualify / match_campus / reject_qualify / pre_assessment / pre_training |
| ≥50 | show_fee / invite |
| ≥70 | report_info / completed |

信任初始值50，每日衰减2。单日加分上限15，单动作类型上限10。
24小时内曾通过某门禁者，低于阈值5分内仍可通行（hysteresis防抖）。

## 企业微信接入

### 接入方式
使用**企微自建应用**（官方API，零封号风险，双向对话）。

### 配置步骤

1. **注册企业微信**：[work.weixin.qq.com](https://work.weixin.qq.com)（免费）
2. **创建自建应用**：管理后台 → 应用管理 → 自建 → 创建应用，记录 `AgentId`
3. **获取密钥**：我的企业 → 企业ID；应用管理 → Secret
4. **配置回调**：URL `http://你的IP:8080/callback/wechat_work`，设置 Token 和 EncodingAESKey
5. **填入 .env**：
   ```bash
   WECHAT_CORPID=企业ID
   WECHAT_AGENTID=应用AgentId
   WECHAT_CORPSECRET=应用Secret
   WECHAT_TOKEN=回调Token
   WECHAT_ENCODING_AES_KEY=回调EncodingAESKey
   ```
6. **重启服务**：`systemctl restart ai-agent`

### 回调接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/callback/wechat_work` | GET | 企微回调验证（echostr） |
| `/callback/wechat_work` | POST | 接收用户消息，异步调用Agent处理并回复 |

### 消息流程
```
用户发消息 → 企微推送回调 → 服务器接收 → 解密
→ 意图分类 → 状态推进 → 合规检查 → 生成回复
→ 加密 → 通过企微API发送 → 存储向量记忆
```

| 接口 | 方法 | 说明 |
|------|------|------|
| `/health` | GET | 健康检查（含LLM/存储/向量状态） |

## 快速开始

### 环境要求
- Python 3.10+
- 豆包API Key（火山引擎）
- 企业微信自建应用

### 安装

```bash
git clone https://github.com/YD-hacker/shengtu-Sales-agent.git
cd shengtu-Sales-agent
pip install -r requirements.txt
cp server_backup/.env.example server_backup/.env
# 编辑 .env 填入 API Key 和企微配置
```

### 启动

```bash
cd server_backup

# 开发模式
python app.py

# 生产模式
gunicorn -c gunicorn_config.py app:app
```

### 健康检查
```bash
curl http://localhost:8080/health
```

## 安全机制

| 机制 | 说明 |
|------|------|
| 辱骂检测 | 识别脏话/辱骂，2次触发人工转接 |
| 信任防刷 | 每日加分上限15，单动作类型上限10 |
| 对话硬上限 | 20轮强制终止（报备阶段可延至25轮） |
| LLM熔断 | 连续失败3次自动切换模板模式 |
| 模糊确认降级 | "嗯""好的"≤3字在关键阶段不直接推进 |
| 频率限制 | 单用户1条/s，10条/min |
| 会话锁 | 用户级并发锁，同用户同时只有一个消息处理 |
| TraceId | 全链路追踪，每次对话唯一标识 |
| 优雅关闭 | SIGTERM时刷盘缓冲区，atexit注册 |
