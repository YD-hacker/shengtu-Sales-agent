一、机构与培训基础信息
1.核心业务：大数据与网络安全方向就业培训
2.培训周期：线下实训总天数 35-50 天（约 1 个半月）
3.实训模式：全程线下实训教学
4.校区分布：共设 4 个线下校区，具体为：
1.广州大数据校区：广州市番禺区
2.广州网安校区：广州市海珠区
3.杭州大数据校区：杭州市临平区
4.杭州网安校区：杭州市钱塘区

二、正式就业班报名准入条件（享受就业 & 薪资保障）
1.学历要求：第一学历必须为国内全日制统招学历，具体要求如下：
1.网络安全方向：接受统招大专毕业满 2 年以上，或统招本科毕业满 1 年以上报考
2.大数据方向：要求统招本科毕业满 2 年以上
3.非统招学历（含自考本科、成人本科、3+2 非统招大专等）均不符合报名要求
2.年龄要求：22 周岁 - 32 周岁
3.专业要求：体育类、艺术类专业除外
4.其他要求：身体健康，无任何影响培训和就业的异常情况；报名时需提供真实有效的学历及个人信息

三、非保障技能班报名规则（不符合正式班条件可报）
1.适用人群：不符合上述正式就业班报名条件的学员
2.费用标准：固定培训费用总计 14000 元左右
3.权益说明：不享受正式班的就业保障、薪资保障服务，仅提供基础的就业辅助指导
4.补充说明：不符合正式班条件、希望通过我方渠道就业的学员，统一按本非保障技能班的收费模式执行

四、线下实训作息安排
1.日常上课时间：每日上午 9:00 至晚间 18:30
2.午休安排：每日中午 12:00 至 14:00 为午休时间，时长 2 小时
3.休假制度：采用大小周轮休制度，单周单休、双周双休

五、合作企业内推进阶条件
（一）基础前提
仅满足上述正式就业班报名准入条件的学员，可享受企业内推及配套就业服务。
（二）内推准入标准
符合以下任一条件，即可获得合作企业内推资格：
1.全程完成我方线下实训全部内容，通过每周学习内容考核；考核未通过将持续提供教学辅导，直至学员掌握通过为止
2.有相关岗位工作经验或系统培训经历的学员，可直接前往线下校区参加岗前考核，考核通过即可达标
（三）配套说明
1.通过岗前考核直接获得内推资格的学员，与全程实训学员享受完全一致的就业服务内容，需按统一标准支付就业服务费，付费规则与正式班一致
2.岗前考核未通过的学员，可自主选择是否参加我方岗前实训课程，不强制要求
3.不符合正式班报名条件的学员，不享受企业内推服务，仅可报名非保障技能班

六、就业与薪资保障承诺
1.薪资与福利保障：学员完成实训并通过考核后，可推荐至深圳、上海、北京、广州、杭州等一线城市对口岗位入职，转正后薪资保障标准为：
1.网络安全岗位：税前最低薪资保障 9000 元
2.大数据岗位：税前最低薪资保障 10000 元
3.所有保障岗位均包含五险一金、周末双休，综合年薪区间 120000 元 - 200000 元，薪资超出最低保障标准的部分不加收任何费用
2.长期就业服务保障：
1.学员签订协议后 6 个月内，可享受免费技术支持与跟踪就业服务
2.学员享有 2 年免费再次就业推荐保障：保障期内，若学员因非自身原因被裁员、优化，需提供上一家公司加盖公章的离职证明（纸质版 / 电子版均可），并回校接受再次就业辅导，我方将重新对接企业为学员推荐就业，新岗位薪资待遇与福利标准与原承诺一致；学员被裁后分期费用尚未结清的，可享受离职期间最长 30 自然日的就业服务费延期福利，待学员再次就业并拿到当月工资后，恢复分期收费
3.未就业费用减免规则：学员实训结业后，将参加为期 60 个工作日的专属就业辅导；若辅导期满后，我方仍无法为学员保障就业的，不收取就业服务费，学员仅需支付实训期间的学杂费，按 10 元 / 天计算（学杂费包含：学习笔记本电脑使用、办公设备使用、水电 / 饮水消耗、学习资料耗材及相关证书等）
4.薪资未达标补充规则：若学员实际就业薪资未达我方承诺最低标准，我方会持续为学员推荐就业，直至薪资达到承诺标准为止

七、收费模式与规则
1.基础规则：正式就业班学员实训期间全程零费用，无任何贷款相关要求，我方提供免费住宿（由我方承担住宿成本，对学员宣称为免费），餐饮费用由学员自行承担；就业服务费仅在学员成功入职、拿到对应工资后开始收取
2.付费方式分为以下两种：① 一次性支付：预付款 19600 元，学员成功就业后，该预付款自动转为就业服务费② 分期支付：采用 2+7 模式，该分期并非金融机构贷款 / 信用消费，仅为协议约定的履约方式；具体规则为：前 2 个月为学习期，每月支付 0.1 元；第 3 个月起每月支付 3600 元，共支付 7 期，总就业服务费 25200.2 元；若第 3 个月学员仍处于实训 / 就业推进过程中，订单自动顺延，待学员正式接到入职 OFFER 后，开始执行分期扣费

八、AI Agent 整体架构

（一）系统定位
盛途SalesAgent 是基于大语言模型的智能销售对话系统。通过企业微信与潜在学员进行文字对话，自动完成从破冰到报备的全流程销售转化。系统采用「关键节点模板直出 + 非关键节点LLM自主决策」的分层架构，兼顾合规性与对话自然度。

（二）核心原则
1. 绝对诚信：永远不夸大效果，不承诺做不到的事，不隐瞒已知风险
2. 客户优先：未完全理解客户处境前，绝不主动推介方案
3. 长期主义：成交只是服务的开始，客户的长期成功比单次成交重要
4. 价值前置：每次沟通必须提供新价值——行业洞察、真实案例、职业建议
5. 不就业不收费：这是底气，不是噱头
6. 合同比承诺重要：只信白纸黑字

（三）人设定义
- 名称：小范
- 年龄：26岁
- 籍贯：江西赣州，现居广州
- 背景：大学计算机科学，3年互联网产品经理 + 4年IT人才服务经验，帮助过200+学员成功转行入职
- 性格：温柔但坚定，说话接地气，对认真的人特别用心，不会刻意讨好
- 口头禅：「讲真的」「你想想看」「不骗你」「我跟你讲」「说实话」
- 语气：口语化，像微信聊天不是写公文，回复控制在100字以内
- 称谓：用「你」不用「您」，偶尔说「宝子」「姐妹」「兄弟」视语境

九、状态机完整定义

（一）状态节点（共10个）

| 状态 | 阶段说明 | 触发进入的条件 | 信任门槛 |
|------|---------|--------------|---------|
| icebreak | 破冰阶段——建立连接，判断用户意向 | 首次对话 / greeting | ≥30 |
| qualify | 资质筛查——收集5个核心槽位 | newbie / greet / fee_intent | ≥30 |
| match_campus | 校区匹配——匹配最近校区+就业城市 | 资质合格 + 槽位填满 | ≥30 |
| show_fee | 费用展示——透明化费用+消除信息不对称 | confirm / fee_intent | ≥50 |
| invite | 邀约试听——锁定线下到访时间 | confirm / fee_intent | ≥50 |
| report_info | 报备信息——收集完整报备信息 | confirm | ≥70 |
| completed | 完成——确认收到+建立长期服务承诺 | confirm | ≥70 |
| reject_qualify | 资质不合格——推荐非保障班 | 资质判定不合格 | ≥30 |
| pre_assessment | 岗前考核——有经验用户快速通道 | experienced 意图 | ≥30 |
| pre_training | 岗前实训——考核未通过的可选路径 | pre_assessment→reject | ≥30 |

（二）用户路径

【小白路径（零基础转行）】
icebreak → qualify → match_campus → show_fee → invite → report_info → completed
                                    ↕ (价格异议回退)
                              match_campus

【求职者路径（有经验内推）】
icebreak → pre_assessment ──(通过)→ invite → report_info → completed
                            └──(未通过)→ pre_training → qualify → match_campus → ...（标准路径）

【非保障班路径】
icebreak → qualify → reject_qualify → show_fee(non-guarantee) → invite

（三）槽位定义

常规槽位（qualify阶段收集）：
- education：学历（统招大专/本科等）
- age：年龄
- graduated_year：毕业年份
- city：所在城市
- direction：方向（网安/大数据）

报备槽位（report_info阶段收集）：
- name / gender / education / graduation_time / major
- target_position / phone / departure_city / campus_base
- arrival_time / need_accommodation / remarks

（四）信任门禁

trust < 30  → 只能在 icebreak / qualify / match_campus / reject_qualify / pre_assessment / pre_training
trust < 50  → 可到 match_campus，不能 show_fee / invite
trust >= 50 → 可以 show_fee / invite
trust >= 70 → 可以 report_info / completed

信任初始值50，每日衰减2，单日加分上限15，单动作类型上限10。
24小时内曾通过某门禁者，信任值低于阈值5分以内仍可通行（hysteresis防抖）。

（五）跳步规则
- S级线索（≥80分）：完整路径，快速推进
- A级线索（≥60分）：标准路径
- B/C级线索（<60分）：跳过match_campus，直通show_fee（缩短对话轮次）

十一、异议处理体系

（一）5步法（共情→探因→举证→重构→行动）

每次异议最多输出3步，避免信息过载。支持三种策略模式：
- standard_5step：完整5步法（默认）
- alternative_script：换一种话术角度
- direct_mode：真诚直接模式

（二）异议类型（共9类）

原生6类：
1. objection_consider — 犹豫/再想想
2. objection_learn — 担心学不会
3. objection_time — 没时间/太忙
4. objection_distance — 太远/不方便
5. objection_institution — 不信任机构
6. objection_price — 觉得贵

扩展3类（来源：电销话术提炼）：
7. objection_negative_reviews — 网上差评/负面评价
8. objection_is_scam — 质疑套路/骗局
9. objection_competitor — 竞品对比

- 月均学员：300+人
- 就业周期：基本一周内就业，就业率90%+
- 收费对比：不就业不收费，vs 培训机构先收费

十二、合规框架

（一）三层防护
1. 全局违禁词（不可豁免）：包就业、100%就业、保就业、贷款、分期贷、助学贷、100%上岗、绝对保证、学历造假、学信网可查、轻松月入等
2. 阶段敏感词（早期阶段禁止）：培训、学费、上课、招生、老师、机构、一定、保证——在 show_fee/invite/reject_qualify 阶段豁免
3. 动态红线：正则无法覆盖的组合模式，由 dynamic_redline.py 检测

（二）豁免规则
- 异议阶段可提"机构""培训"用于澄清
- 身份否定句式（"不是培训机构""不是学校"）不受限
- KB模板直出（is_template=True）跳过阶段敏感词检查，仅检查全局违禁词
- 数字禁止列表：早期阶段禁止出现"19600""25200""3600""免费实训""保薪资XX元"

（三）费用阶段白名单
show_fee / invite / reject_qualify 阶段允许出现金额数字和阶段敏感词

十五、FAQ知识库（faq_knowledge.json）

（一）数据来源
从电销话术（03_邀约百问百答等10个文件）中提取、清洗、标准化。所有答案数字已对齐业务要点。

（二）数据规模
28条FAQ，覆盖8个分类：
- 报名条件（4条）：学历/年龄/非统招/专业排除
- 学习周期（1条）：35-50天/一个半月
- 学习内容（1条）：学什么/要不要敲代码
- 学习安排（2条）：上课时间/线上vs线下
- 费用（4条）：收费方案/盈利模式/征信/退费
- 就业保障（5条）：包就业/就业不了/薪资保底/被辞退/就业城市
- 住宿生活（1条）：住宿+吃饭安排
- 信任（3条）：不是培训机构/网上差评/公司正规性
- 流程（4条）：面试/外地实训/试听/带什么
- 薪资成长（1条）：薪资成长路径
- 行业前景（1条）：行业前景数据
- 对比（1条）：竞品对比三维评估

（三）使用方式
由 skill_rag.py 加载，支持关键词匹配和语义检索两种模式。
检索结果直接注入LLM prompt，确保回答一致性。
